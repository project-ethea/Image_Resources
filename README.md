# Project Ethea Image Resources

This repository contains the original versions of certain image files used by
the Project Ethea campaigns, as well as the Naia resources library. These
files are provided in the following formats:

| Format       | Extensions      | Layered          |
|--------------|-----------------|:----------------:|
| PNG          | `.png`          |                  |
| WebP         | `.webp`         |                  |
| GIMP         | `.xcf`          | ✓️                |
| Krita        | `.kra`          | ✓️                |
| OpenRaster   | `.ora`          | ✓️                |

The files in here are provided for convenience purposes, in particular in the
event that they need to be updated in the future due to changes to the game's
user interface or graphics rendering system. The same licensing used for their
game-optimized counterparts applies to them.
